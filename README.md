Formação em Desenvolvimento de Software
Repositório dedicado à consolidação dos fundamentos de algoritmos e lógica de programação.

Objetivo: Construir uma base sólida em engenharia de software, partindo da lógica pura em pseudocódigo (VisualG) até o desenvolvimento robusto com Java e Spring Boot.

📂 Módulos do Repositório
01-estrutura-sequencial: Variáveis, tipos de dados, operadores aritméticos e entrada/saída. * 02-estrutura-condicional: (Em progresso) Tomada de decisão, operadores lógicos (e, ou, nao) e encadeamentos .


Disponível para desafios técnicos e projetos que exijam lógica apurada e visão de negócio.
