# Laboratório de Fundamentos de Programação 💻

Este repositório é o meu **Laboratório de Fundamentos**, onde documento minha base sólida em lógica de programação e engenharia de software.

---

## 🧬 Estrutura do Laboratório

A organização reflete a progressão lógica do aprendizado de engenharia:

*   **Logica Sequencial:** Resolução de problemas lineares, focando em entrada, processamento e saída.
*   **Estrutura Condicional:** Tomada de decisão e controle de fluxo complexo.
    *   **Destaque:** `EXTRA_VIABILIDADE_LOTEAMENTO.ALG` - Um desafio de lógica de negócio que simula a viabilidade financeira de um empreendimento imobiliário.

---

## 🔬 Metodologia de Engenharia

Minha abordagem para resolver problemas complexos segue o fluxo:
1.  **Análise de Requisitos:** Entendimento profundo do problema de negócio.
2.  **Abstração Lógica:** Modelagem do problema em algoritmos estruturados (`.ALG`).
3.  **Implementação de Referência:** Validação da lógica antes da transposição para stacks modernas.
